## Sobre o Repositório

Este espaço é dedicado ao estudo prático e à documentação do meu aprendizado contínuo na linguagem JavaScript. O objetivo do repositório é servir como um histórico da minha evolução técnica, saindo da lógica de programação base e avançando para o ecossistema web e manipulação de dados.

Todo o material aqui presente reflete códigos de estudo, testes de conceitos e pequenos projetos de fixação.

## Tópicos Abordados

O repositório está organizado para cobrir desde a sintaxe base até conceitos modernos da linguagem (ES6+):

* **Fundamentos:** Variáveis (let, const), tipos de dados e operadores
* **Controle de Fluxo:** Condicionais e laços de repetição
* **Funções:** Declarações clássicas, Arrow Functions e Callbacks
* **Estruturas de Dados:** Manipulação de Arrays e Objetos
* **Manipulação da Web:** Interação com o DOM (Document Object Model) e Eventos
* **Assincronismo:** Promises, Async/Await e consumo de APIs (Fetch)
